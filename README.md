# ⚡ BinarySight: System Blueprint & Code Sandbox

A highly responsive, dark-mode-first cyberpunk UI environment built to showcase modular development systems. It includes an interactive curriculum engine, an active billing toggle matrix, and an entry-level code playground panel.

## ✨ Core Architectures

* **🌗 Dual-Theme Matrix:** Pure CSS token system that transitions dynamically between a deep cyberpunk slate theme and a bright, crisp light mode surface.
* **💳 Glitch-Free Subscriptions:** A unified structural component system running real-time monthly/yearly plan toggles with zero layout shifting.
* **🔐 Isolated Portal Flow:** Blur-backed modal systems that enforce responsive overlay configurations cleanly across both themes without layout bleeding.
* **💻 Structural Code Sandbox:** A safe web interface blueprint simulating local compilation pipelines and terminal feedback queues.

## 🛠 Tech Stack

* **Structure:** Semantic HTML5 layouts with secure grid container definitions.
* **Typography & Styles:** Tailored Google Fonts (`Plus Jakarta Sans`, `Poppins`, `Fira Code`) mapped natively to CSS variable matrices.
* **Interactions:** Modern event loops built in vanilla JavaScript (ES6+ Modules).

## 🚀 Quick Start Environment

To launch this architecture locally:

1. Clone this system blueprint directly from your terminal:
   ```bash
   git clone https://github.com
   ```
2. Navigate directly into the project matrix directory:
   ```bash
   cd YOUR-REPOSITORY-NAME
   ```
3. Open `home.html` inside your favorite browser engine to initialize the components instantly.
